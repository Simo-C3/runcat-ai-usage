# データ保存とプライバシー

すべての処理と履歴保存はローカルで行います。認証情報は各サービスへの
リクエスト時だけ読み取り、このプロジェクトのファイルには保存しません。

## 保存場所

| パス | 内容 |
| --- | --- |
| `~/RunCatMetrics/*.json` | RunCat Neoが読む3サービスのスナップショット |
| `~/Library/Application Support/RunCat AI Usage/state/display.json` | 表示設定 |
| `.../state/cache/*.json` | 最後に成功した利用量と取得時刻。Claudeはサインインごとに分離 |
| `.../state/history.db` | 利用量の時系列（SQLite）。Claudeはサインインごとに分離 |
| `~/Library/Logs/RunCat AI Usage/` | 標準出力とエラーログ |
| `~/Library/LaunchAgents/dev.runcat.ai-usage.plist` | 1分間隔の起動設定 |

`...` は `~/Library/Application Support/RunCat AI Usage` を表します。

## 履歴

- 絶対使用量を取得できるサービスだけ、サービスごと（Claudeはサインインごと）に
  1分単位で記録します。
- `Today / 1h` はローカル日付の午前0時以降と直近60分の増加量です。
- 推移は設定期間を7等分し、各区間の増加量を相対的な棒で表示します。
- 契約期間の更新などでカウンターがリセットされた場合は、新しい期間の使用量を
  続けて加算します。一時的に小さい値が返った場合は回復するまで無視します。
- 最大設定期間365日と計算用の1日分を保持し、366日より古い記録を削除します。

履歴はインストール後に蓄積されます。サービス側から過去の時系列を取得しないため、
インストール前の履歴は復元できません。

## キャッシュと障害時の動作

API取得は標準で55秒以内に重複しないよう制限します。取得に失敗した場合は
最後に成功した値を維持し、エラーだけをログへ記録します。あるサービスの失敗で
ほかのサービスの更新が停止することはありません。

Claudeでは、資格情報内のアカウントまたは組織IDを優先し、なければ資格情報の
トークンから算出した非可逆の識別子を使用します。この識別子はキャッシュ名と
履歴の分離にだけ使い、トークンやアカウント名を保存しません。

JSONと設定ファイルは一時ファイルからの置換で更新し、RunCat Neoが書き込み途中の
内容を読まないようにしています。

## 削除

通常のアンインストールでは履歴とJSONを残します。すべて削除する場合は、Formulaを
削除する前に `--purge` を指定します。

```sh
runcat-ai-usage-uninstall --purge
brew uninstall runcat-ai-usage
```

RunCat Neoに登録したCustom Metrics Sourceはアプリ側で別途削除してください。
認証情報の参照元は[SECURITY.md](../SECURITY.md)を確認してください。
